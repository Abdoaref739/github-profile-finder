# github-profile-finder
### A simple website made with HTML, CSS, JS, and github RESTful API to check users profiles by entering their profile username...
## How to use it!
### It is so simple, u enter the usernme correctly in the field and then click on the search button. You'll get the username, profile pic., no. of following and followers, the date of creation of the account, and finally, the no. of repos created!
